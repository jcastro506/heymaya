# maya-gtm-tools

Typed OpenClaw tools for the ClawLaunch GTM agent ("Maya"). Replaces hand-written
`curl`-through-`exec` for both **research reads** (ScrapeCreators / TwitterAPI.io /
Algolia HN) and **persistence writes** (Convex `/lc_gtm/*`).

The model emits a schema-validated function call; the plugin runs the real HTTP
request server-side from the machine's `CONVEX_SITE_URL` / `HOOK_TOKEN` /
`SCRAPECREATORS_API_KEY` / `TWITTERAPI_IO_KEY` env. No shell, no escaping, no
missing required fields. A research worker cannot fabricate — data only exists if
the typed call actually ran.

## Loading

Built into the deploy bundle (`convex/agents/packs/maya_gtm/bundledGtmPlugin.ts`,
generated by `scripts/sync-bundled-gtm-plugin.ts`). At machine boot the bootstrap
shell installs it via `openclaw plugins install npm-pack:<tgz>` and the gateway
config allowlists `maya-gtm-tools`. Activates `onStartup`; subagents inherit it.

## Editing

After changing `index.js`, update `openclaw.plugin.json` `contracts.tools` to match
the tool names, then re-run `npx tsx scripts/sync-bundled-gtm-plugin.ts` to refresh
the base64-inlined bundle that the Convex deploy ships.
